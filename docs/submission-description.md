# PackProof

PackProof helps small retailers review supplier deliveries with a clearer record. A receiver enters expected items and adds a delivery photo. In live mode, Gemini on Vertex AI, called through the Google Gen AI SDK, proposes structured observations of visible labels, counts, damage, and uncertainty. Application code compares observations with expected quantities. The receiver can edit each count and must confirm every line before export. Sealed or partly obscured contents remain unresolved until the operator physically checks and confirms a count; a photo alone cannot establish the shipment total. The exported report keeps the evidence source and operator-confirmed values together. Clearly labeled fixture mode loads a fixed synthetic case without calling Gemini; the current demo uses this mode. The Vertex AI adapter is implemented, but live inference still needs a configured Google Cloud project and a verified run. The documented Cloud Run deployment serves the React workspace and Express API together; Secret Manager can provide the stable case-signing secret. Deployment has not been verified. PackProof flags candidate discrepancies and leaves receipt and supplier decisions to the operator.
